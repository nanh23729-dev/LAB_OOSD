## 📖 Giới thiệu

Repo này lưu lại toàn bộ **bài thực hành (LAB1 → LAB9)** của môn **OOSD** (Object-Oriented Software Development).
Mỗi LAB là một thư mục độc lập, có source code C# và script SQL Server đi kèm (nếu có).

## 🚀 Cách chạy

1. **Clone repo**
   ```bash
   git clone https://github.com/nanh23729-dev/LAB_OOSD.git
   ```
2. Mở thư mục LAB muốn chạy (ví dụ `LAB5`).
3. Mở file `.sln` bằng **Visual Studio**.
4. Nếu LAB có database: chạy file `.sql` trong SQL Server Management Studio, rồi sửa **connection string** cho khớp máy bạn.
5. Nhấn **F5** để chạy.
